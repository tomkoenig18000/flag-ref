# Flag Ref

Scoreboard, game clock, stop-time alerts and a quick-reference rulebook for refereeing UBC Point Grey Cup flag football. Runs as a home-screen app on any phone and works offline.

**Use it:** open https://tomkoenig18000.github.io/flag-ref/ in Safari → Share → Add to Home Screen.

Source in `src/app.html`; `python3 build.py` produces the site in `docs/`; tests in `qa/`. See `CLAUDE.md` for the working notes.
